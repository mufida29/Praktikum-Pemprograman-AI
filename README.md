## 🌷 Tentang Repository

Repository ini merupakan tempat penyimpanan dokumentasi dan hasil pengerjaan tugas praktikum mata kuliah **Pemrograman Artificial Intelligence (AI)**.

Dalam repository ini terdapat berbagai latihan dan implementasi program menggunakan bahasa Python serta library yang mendukung pengolahan data, visualisasi, dan pembelajaran mesin.

Repository ini dibuat sebagai bagian dari proses pembelajaran untuk memahami konsep dasar serta penerapan Artificial Intelligence dalam pemrograman.

---

## 🎯 Tujuan Praktikum

- Memahami dasar bahasa pemrograman Python.
- Mengenal library Python untuk Artificial Intelligence.
- Mempelajari pengolahan dan analisis data.
- Memahami visualisasi data menggunakan Python.
- Mengenal konsep dasar Machine Learning.
- Mengimplementasikan program sederhana berbasis AI.
